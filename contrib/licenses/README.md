# Third-party licenses

The desktop application bundles the default fonts of `egui`/`epaint`
(`epaint_default_fonts`):

- Ubuntu Light — Ubuntu Font Licence 1.0 (`Ubuntu-font-1.0.txt`).
- Noto Emoji — SIL Open Font License 1.1 (`OFL-1.1.txt`).
- Hack — MIT (`Hack-font.txt`).
- Emoji Icon Font — MIT (`emoji-icon-font-MIT.txt`).

The licenses must travel with any distributed artifact that contains the fonts. The release
tarball includes this directory for that reason.
